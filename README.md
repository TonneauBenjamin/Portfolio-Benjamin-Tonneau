## 📌 Présentation

Ce portfolio a été conçu pour offrir une vitrine claire et interactive à destination des recruteurs, ingénieurs et collaborateurs. Il intègre :
- **Bilinguisme dynamique (FR / EN)** avec basculement instantané sans rechargement de page.
- **Téléchargement direct de CV** (versions française et anglaise à jour).
- **Showcase de projets** avec filtres, descriptions détaillées de l'architecture, métriques clés et liens directs vers les dépôts GitHub correspondants.
- **Grille de compétences** (Data Engineering, ML, Cloud & DevOps, Langages de programmation).
- **Design moderne, sobre et responsive** (typographies *Familjen Grotesk*, *Public Sans* et *JetBrains Mono*).

---

## 🛠️ Stack Technique

- **Frontend :** HTML5 sémantique, CSS3 moderne (Variables CSS, Flexbox, Grid), JavaScript (ES6+ natif sans framework lourd).
- **Hébergement & Déploiement :** GitHub Pages avec intégration continue.
- **Typographie & Icônes :** Google Fonts, SVG vectoriels.

## 💻 Exécution en local

Pour tester le portfolio en local :

```bash
# Cloner le dépôt
git clone https://github.com/TonneauBenjamin/Portfolio-Benjamin-Tonneau.git
cd Portfolio-Benjamin-Tonneau

# Lancer un serveur local léger (Python)
python3 -m http.server 8000
```
Puis ouvrir `http://localhost:8000` dans votre navigateur.
